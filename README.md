# Rizky Esa Gumilar — Strategic Finance & Decision Intelligence

Personal portfolio site. Live at
**https://alfaname.github.io/rizky-esa-gumilar-portfolio/**

Financial clarity for faster decisions — the site shows how fragmented financial
and operational information becomes a trusted management view, and how that view
turns into a decision.

## About the figures

Every number on this site is a **public-safe reconstruction**. What is preserved
is the financial logic of real reporting work: the calculation chain, the
relationships between lines, the category structure and the management question
behind each view. What is deliberately not preserved is any confidential value,
company, client, project, product, person or account. None of the figures should
be read as the results of any organisation.

## Built with

Static HTML, CSS and vanilla JavaScript — no build step, no framework, no
third-party runtime. Charts are hand-rolled SVG with a keyboard-reachable
tooltip and a data-table view for every chart. Motion is scroll-driven and fully
respects `prefers-reduced-motion`. Fonts are self-hosted (SIL Open Font License):
Fraunces, Plus Jakarta Sans and IBM Plex Mono.

## Local preview

Any static file server works, for example:

```bash
npx serve .
```
